## ⚡ The 10-minute daily loop

Once the system is running, a normal day costs about **40 minutes**:

1. **Open** [`CALENDAR-30-DAY.md`](CALENDAR-30-DAY.md) → find today.
2. **Record** the Short (screen-record WhatsApp, 30 seconds, one take).
3. **Post** to TikTok + YouTube Shorts + WhatsApp Status + Telegram.
4. **Paste** the caption from [`CAPTIONS.md`](CAPTIONS.md) — the CTA is already in it.
5. **Sunday only:** record the week's long video + update [`TRACKER.md`](TRACKER.md).

---

## 🎯 The one rule

Every single piece of content ends with the same three-part CTA:

> **"Star the repo, fork it, and subscribe — link in the description."**

Repetition is what converts viewers into stars. Do not get creative with the CTA.
